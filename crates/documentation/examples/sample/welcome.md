# Welcome to Macro

Extremely fast, unified interface for all your work, all linked together in one database.

Macro unifies your email, messaging, tasks, docs, and files into a single system. We built it with a Solid frontend and a Rust backend, so it's fast.

> **Getting started** — New to Macro? Go from a fresh account to a working setup in about 15 minutes. See [Get Started](/getting-started).

## Core Blocks

For each block, we've studied the best prior art and tried to make it even better.

| Block | Prior art | What's better |
| ----- | --------- | ------------- |
| Email | Superhuman | Faster, unified inbox |
| Messages | Slack | More focused, less noisy |
| Docs | Notion | Simpler, markdown-native |
| Tasks | Linear | Less ceremonious |

## Key Features

- **Bidirectional @linking**: mention a doc in a message and both know about each other.
- **Intelligent permissions**: anything you @mention in a channel is automatically shared with its members.
- **Built for speed**: keyboard-first everywhere. Try pressing `/` to search this site.
